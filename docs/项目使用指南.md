# AIX Health（RetinaEcho 数字记忆相框）使用指南

> **项目简介**：面向阿尔茨海默病（AD）及轻度认知障碍（MCI）患者的数字记忆相框系统。  
> 患者端为拟物化数字相框，家属端为手机 PWA 应用，通过共享后端实现记忆资产实时同步与认知干预闭环。

## 1. 系统架构概览

```
┌──────────────────┐       ┌──────────────────┐
│   患者端 (相框)   │       │  家属端 (手机 PWA)│
│  patient-app/    │       │  caregiver-app/  │
│  HTML+CSS+JS     │       │  HTML+CSS+JS     │
│  纯前端演示       │       │  纯前端演示       │
└───────┬──────────┘       └───────┬──────────┘
        │                          │
        │     ┌────────────┐      │
        └─────┤  FastAPI   ├──────┘
              │  后端 API   │
              │ :8000       │
              ├────────────┤
              │ PostgreSQL │
              │ MinIO      │
              │ LLM API    │
              └────────────┘
```

### 两个前端 + 一个后端

| 模块 | 目录 | 说明 |
|:---|:---|:---|
| **家属端** | `caregiver-app/` | 家属手机上的 PWA 应用，微信风格对话交互 |
| **患者端** | `patient-app/` | 数字相框，含 COLD_START / STANDBY / CHAT / SOOTHING 四状态 |
| **家属端（豪华版）** | `frontend/` | 另一个家属端实现，纯 CSS 拟物风格（独立使用） |
| **后端** | `backend/` | FastAPI + PostgreSQL + MinIO + LLM 引擎 |

### 核心业务流程

```
患者端开机 → 显示设备码/二维码 [COLD_START]
     ↓
家属扫码绑定 → 签署知情同意 → 初始化配置（年代/地区/语言/数字人名称）
     ↓
患者端检测到配置就绪 → 进入轮播待机 [STANDBY]
     ↓
家属通过对话流录入记忆（文字/语音/照片）→ LLM 提取实体 → 同步至患者端
     ↓
患者端语音唤醒 → 进入对话模式 [CHAT] → 数字人引用记忆进行交互
     ↓
负面信号检测 → 日落舒缓模式 [SOOTHING] → 播放白噪音
```

- **操作系统**：Windows / macOS / Linux

## 3. 后端启动

> 如果只需要体验前端交互，**可以跳过本节**，前端默认使用 Mock API 模拟数据。

### 3.1 环境变量配置

```bash
# 复制后端环境变量模板
cp backend/.env.example backend/.env

# 编辑 backend/.env，修改关键配置
```

关键配置项（`backend/.env`）：

```ini
# PostgreSQL 数据库
DATABASE_URL=postgresql+asyncpg://postgres:password@localhost:5432/aixhealth

# MinIO 对象存储 (可选)
MINIO_ENDPOINT=localhost:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin

# LLM API (用于实体抽取和对话生成)
LLM_ENDPOINT=https://api.openai-next.com/v1
LLM_API_KEY=sk-your-key
LLM_MODEL=deepseek-v4-flash
LLM_PROVIDER=openai-next
```

### 3.2 安装 Python 依赖

```bash
cd backend

# 推荐使用虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/macOS
# 或 venv\Scripts\activate  # Windows

pip install -r requirements.txt
```

### 3.3 初始化数据库

```bash
# 确保 PostgreSQL 已启动，且数据库 aixhealth 已创建

# 方式 A：通过 main.py 自动创建表（推荐）
# 直接启动后端，FastAPI 的 lifespan 事件会自动创建所有表

# 方式 B：通过 Alembic 迁移
alembic upgrade head
```

### 3.4 启动后端

```bash
cd backend
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

启动后访问：
- API 文档：http://127.0.0.1:8000/docs
- 健康检查：http://127.0.0.1:8000/health

### 3.5 后端服务依赖一览

| 服务 | 必需？ | 说明 |
|:---|:---|:---|
| PostgreSQL | ✅ 必需 | 主数据库（SQLAlchemy + asyncpg） |
| MinIO | ❌ 可选 | 照片/语音文件存储，无则使用本地文件 |
| LLM API | ❌ 可选 | 实体抽取 + 对话生成，无则降级为默认回复 |
| ASR 服务 | ❌ 可选 | 语音识别，演示模式下用模拟数据 |
| TTS 服务 | ❌ 可选 | 语音合成，演示模式下用模拟数据 |

## 4. 前端启动

### 4.1 家属端（Caregiver App）

**位置**：`caregiver-app/index.html`

家属端是一个移动端 PWA，打开方式：

```bash
# 方式 1：直接浏览器打开
# 双击 caregiver-app/index.html

# 方式 2：通过 HTTP 服务器（推荐）
cd caregiver-app
python -m http.server 8081
# 访问 http://127.0.0.1:8081
```

**两种运行模式**：

| 模式 | 文件 | 说明 |
|:---|:---|:---|
| **Mock 模式（默认）** | `js/mock-api.js` | 纯前端演示，所有数据为模拟，无需后端 |
| **真实模式** | `js/api.js` | 覆盖 MockAPI，连接真实后端 `127.0.0.1:8000` |

切换真实模式：页面会自动加载 `api.js`（在 `mock-api.js` 之后加载），覆盖同名函数。无需手动配置。

**家属端功能**：

| Tab | 功能 | 说明 |
|:---|:---|:---|
| 💬 对话流 | 记忆录入 | 文字输入 / 按住录音 / 选择照片 → LLM 自动提取实体 |
| 🗂️ 记忆库 | 记忆管理 | 按标签（年代/地点/事件/喜好）筛选，查看/编辑/删除 |
| 📊 每日简报 | 认知洞察 | 活力指数环形图、高共鸣话题 Top 3、沟通建议 |

### 4.2 患者端（Patient App）

**位置**：`patient-app/index.html`

患者端是数字相框，打开方式：

```bash
# 方式 1：直接浏览器打开
# 双击 patient-app/index.html

# 方式 2：通过 HTTP 服务器
cd patient-app
python -m http.server 8082
# 访问 http://127.0.0.1:8082
```

**患者端状态机**：

```
COLD_START ──(config_ready)──→ STANDBY
STANDBY    ──(speech_detected)──→ CHAT
STANDBY    ──(negative_signal)──→ SOOTHING
CHAT       ──(silence_timeout)──→ STANDBY
CHAT       ──(sunset_trigger)──→ SOOTHING
SOOTHING   ──(settled_timeout)──→ STANDBY
```

| 状态 | 含义 | 表现 |
|:---|:---|:---|
| **COLD_START** | 等待绑定 | 显示 6 位设备码 + 二维码 |
| **STANDBY** | 轮播待机 | 老照片自动轮播 |
| **CHAT** | 对话中 | 数字人形象 + 大字幕 + 声波动画 |
| **SOOTHING** | 舒缓模式 | 暖色遮罩 + 白噪音标识 |

**演示调试**：患者端在 `window.__debug` 暴露了调试接口：
```js
// 在浏览器控制台中调用
window.__debug.triggerChat()     // 手动触发对话模式
window.__debug.triggerSoothing() // 手动触发舒缓模式
```

### 4.3 豪华家属端

**位置**：`frontend/index.html`

另一个家属端实现，具有高度拟物化的 UI 设计。打开方式与家属端相同。

## 5. 全流程跑通（演示模式）

> 无需任何后端服务，纯前端即可体验完整流程。

### 第一步：打开患者端

1. 打开 `patient-app/index.html`
2. 看到 **COLD_START** 界面：显示设备码 `ABC123` 和二维码
3. 记下这个设备码（后续绑定用）

### 第二步：打开家属端

1. 打开 `caregiver-app/index.html`
2. 看到主界面（模拟已绑定状态）
3. 左上角显示患者名称"张伯伯"和绿色在线圆点

### 第三步：录入记忆

1. 在对话流 Tab 的输入框中输入文字，例如：
   - *"我爸以前在广州造船厂上班，每天下班都带我去江边看船"*
   - *"小时候过年最喜欢去外婆家，她做的年糕特别好吃"*
   - *"阿珍是我老伴，我们是在厂里认识的，她唱歌特别好听"*
2. 点击发送按钮（➤）
3. 系统"正在分析记忆..." → 弹出**记忆卡片**，展示 LLM 抽取的实体：
   - 年代、地点、事件、喜好、可信度
4. 点击**确认**按钮模拟记忆同步

### 第四步：查看记忆库

1. 切换到 🗂️ 记忆库 Tab
2. 看到所有已录入的记忆卡片
3. 可通过顶部标签栏筛选（全部/年代/地点/事件/喜好）

### 第五步：查看每日简报

1. 切换到 📊 每日简报 Tab
2. 看到：
   - **活力指数**：环形进度条 + 状态文案
   - **高共鸣话题 Top 3**：基于对话时长和轮次
   - **沟通建议**：AI 生成的沟通切入点建议
3. 可选择不同日期查看历史简报

### 第六步：体验患者端状态切换

在患者端页面打开浏览器控制台（F12），输入：

```js
// 模拟配置就绪 → 进入轮播待机
window.__debug.stateMachine.transition('config_ready')

// 模拟语音唤醒 → 进入对话模式
window.__debug.triggerChat()

// 等待几秒，观察对话交互
// 数字人会显示回复字幕

// 模拟负面信号 → 进入舒缓模式
window.__debug.triggerSoothing()
```

## 6. 全流程跑通（真实后端模式）

> 连接真实后端，实现数据持久化和 LLM 驱动的智能交互。

### 前置条件

- [ ] PostgreSQL 已启动且数据库 `aixhealth` 已创建
- [ ] （可选）MinIO 已启动
- [ ] （可选）LLM API Key 已配置
- [ ] 后端已启动（`uvicorn app.main:app --reload --port 8000`）

### 第一步：准备测试数据

由于绑定流程需要数据库中已有患者记录，建议通过 API 直接插入一条：

```bash
# 直接通过 API 文档操作
# 访问 http://127.0.0.1:8000/docs
```

或在后端代码中添加种子数据脚本，或直接 SQL：

```sql
INSERT INTO patients (id, device_code, display_name, status)
VALUES ('58b203df-5424-4f53-b155-82b34f840213', 'ABC123', '张伯伯', 'active');
```

> 家属端和患者端的 `api.js` 中硬编码了测试患者 ID `58b203df-5424-4f53-b155-82b34f840213`，请确保数据库中存在此记录或用你的 ID 替换。

### 第二步：启动前端（真实模式）

前端文件加载顺序：
1. `mock-api.js` — 先加载模拟 API
2. `api.js` — 后加载，覆盖 MockAPI 函数为真实后端调用

**无需任何额外配置**，只需确保后端运行在 `http://127.0.0.1:8000`。  
如果后端地址不同，修改 `api.js` 中的 `BASE` 常量。

### 第三步：扫码绑定（模拟）

当前前端未实现扫码 UI，可通过控制台测试：

```js
// 家属端控制台
MockAPI.scanBinding('ABC123').then(console.log)
```

返回示例：
```json
{
  "patient_id": "58b203df-...",
  "device_code": "ABC123",
  "is_new": true,
  "role": "admin",
  "patient_name": "张伯伯"
}
```

### 第四步：签署知情同意

```js
MockAPI.signConsent({
  caregiver_name: "李娟",
  caregiver_phone: "13800138000",
  patient_id: "58b203df-..."
}).then(console.log)
```

### 第五步：完成初始化配置

```js
MockAPI.completeConfig({
  patient_id: "58b203df-...",
  era: "1980s",
  region: { country: "CN", province: "广东", city: "广州" },
  language: "zh-CN",
  persona_name: "强叔"
}).then(console.log)
```

### 第六步：录入真实记忆

```js
MockAPI.submitMemory({
  patient_id: "58b203df-...",
  raw_text: "我爸以前在广州造船厂工作，每天带我去江边看船"
}).then(console.log)
```

后端会：
1. 调用 LLM 进行实体抽取（年代/地点/事件/喜好）
2. 将记忆写入 PostgreSQL
3. 返回结构化实体和置信度

### 第七步：查看每日简报

```js
MockAPI.getBrief("2026-09-05").then(console.log)
```

后端会：
1. 查询当日对话和分析数据
2. 计算活力指数
3. 返回高共鸣话题和沟通建议

### 第八步：患者端对话

患者端通过轮询 `/api/v1/patients/config` 检测配置状态。配置就绪时自动从 COLD_START 进入 STANDBY。

患者语音唤醒后，调用 `/api/v1/chat/message`：
1. 后端检索患者相关记忆
2. 构造"老街坊"角色 prompt
3. 调用 LLM 生成回复（40 字以内，不纠错时空错位）
4. （可选）TTS 合成语音

## 8. 常见问题

### Q1：页面打开后数据都是模拟的，如何连接真实后端？

前端默认使用 `mock-api.js` 中的模拟数据。`api.js` 文件在 `mock-api.js` 之后加载，会自动覆盖 MockAPI 的同名函数，将请求转发到真实后端。

**无需修改代码**，只需：
1. 确保后端已启动（`http://127.0.0.1:8000`）
2. 确保数据库中有对应的测试患者数据
3. 刷新前端页面即可

如果后端地址不是 `127.0.0.1:8000`，修改对应 `api.js` 文件顶部的 `BASE` 常量。

### Q2：打开患者端后一直显示 COLD_START，如何进入 STANDBY？

**演示模式**：在浏览器控制台中输入：
```js
window.__debug.stateMachine.transition('config_ready')
```

**真实模式**：需要后端返回配置就绪状态（`asset_pack.status === 'ready'`），患者端的轮询检测到后会自动转换。

### Q4：数据库连接失败怎么办？

检查 `backend/.env` 中 `DATABASE_URL` 是否正确：
```ini
DATABASE_URL=postgresql+asyncpg://用户名:密码@localhost:5432/aixhealth
```

确保 PostgreSQL 已启动且数据库已创建：
```sql
CREATE DATABASE aixhealth;
```

### Q5：LLM 调用报错怎么办？

实体抽取和对话引擎依赖 LLM API。如果未配置或调用失败，系统会自动降级：
- **实体抽取**：降级为原文入库，confidence=0
- **对话引擎**：返回默认回复

如需配置 LLM，在 `.env` 中设置：
```ini
LLM_ENDPOINT=https://api.openai-next.com/v1
LLM_API_KEY=sk-your-key
LLM_MODEL=deepseek-v4-flash
LLM_PROVIDER=openai-next
```

### Q6：照片显示不出来？

患者端的照片为内联 SVG 占位图，无需实际图片文件。如果 SVG 不显示，检查浏览器是否支持 `data:image/svg+xml` 格式。

### Q7：如何只测试某个功能模块？

每个 API 路由都可以通过 Swagger 文档独立测试：
- 访问 http://127.0.0.1:8000/docs
- 选择对应的 API
- 点击 "Try it out" 输入参数
- 查看请求和响应

## 附录：技术栈

| 层 | 技术 | 说明 |
|:---|:---|:---|
| 前端（家属端） | 原生 HTML/CSS/JS + PWA | 无框架依赖，支持安装到手机桌面 |

| ASR/TTS | 预留接口 | 语音识别与合成，可接入 FunASR / Coqui TTS |
| 推送 | Web Push (VAPID) | PWA 系统级推送通知 |
| 定时任务 | APScheduler | 每日简报生成等后台任务 |
