# **数字记忆相框（患者端） PRD（MVP 开发版）**

* **文档版本**：v1.4.0（待机监听、双语、舒缓背景音与云端隐私修订版）  
* **日期**：2026-09-05  
* **产品名称**：数字记忆相框（患者端）  
* **一句话定位**：面向阿尔茨海默病患者的浏览器全屏 Web 应用——以“老街坊数字人相框”形态提供云端零操作冷启动、怀旧陪聊、无感认知活力参考监测与日落舒缓干预。  
* **赛事对标**：AIx Origin Summit 2026 · Vital 活域赛道。对齐评审五要素：真实痛点 / 专业融合 / 可演示闭环 / 免责与伦理 / 落地思考。

## **1\. 产品概述**

### **1.1 背景与真实痛点**

* 中国 60 岁以上人群中阿尔茨海默病患者约 1000 万，其中轻中度患者绝大部分居家照护。  
* 核心痛点：家属照护压力大、缺乏沟通方法（不敢聊、不会聊）；患者对“AI 助手”有距离感。  
* 本系统定位为**非临床的陪伴与干预工具**：不做诊断、不替代医嘱。

### **1.2 目标用户**

* **直接用户**：阿尔茨海默病患者。默认**不具备阅读与配置能力**：全流程零文字输入、操作 \<= 2 次点击，配置责任完全移交家属端（云端下发）。  
* **演示受众**：Vital 赛道评委（评审偏好数字弱势群体、双语（普通话及英语）适配、有边界的陪伴）。

### **1.3 运行载体**

* 浏览器全屏 Web（iPad / PC，Safari / Chrome）。  
* 依赖设备前置摄像头（眼动追踪）与麦克风（声学采集、ASR），首次进入需授权。  
* 部署形态：演示时笔记本电脑做网页 UI 相框外壳模拟。

### **1.4 技术底座**

| 能力 | 技术 | 说明 |
| :---- | :---- | :---- |
| 眼动/视线追踪 | MediaPipe FaceMesh（浏览器端） | 定位 468 个面部关键点中的虹膜中心（468/473），判断注视落点；本地计算；授权原始视频及特征加密上传云端保存 |
| 声学特征 | Web Audio API（浏览器端） | 本地实时计算停顿潜伏期、语速、停顿比率、音量包络；授权原始音频及特征加密上传云端保存 |
| 对话引擎 | 后端 FastAPI \+ LLM（GLM5.3flash（暂定，可更换模型）） | 验证疗法 Prompt 路由，角色双层体系见第 3 章 |
| 语音 | 普通话 / 英语 ASR \+ TTS | TTS 语速 0.85x；命中人物语音样本时使用零样本克隆音色（见 3.3） |
| 声音克隆 | 零样本克隆（OpenVoice v2 / CosyVoice 零样本模式） | 数秒参考音频克隆音色，CPU/低配 GPU 可跑；不做微调训练（现场不可控） |
| 照片活化 | LivePortrait（预生成） | 单张照片生成“待机微动视频”（眨眼、轻微点头），预生成规避实时延迟 |

### **1.5 MVP 功能范围**

**纳入（P0）**：云端配置冷启动与设备绑定、待机老照片轮播、验证疗法双语对话（含照片亲人模式与声音克隆）、眼动/声学认知活力参考指标采集、日落综合征舒缓模式、双端真实上传 Demo 闭环。

**不纳入（范围外，见第 14 章）**：独立 GAMMA 干预模式、待机定时主动搭话、注视唤醒/待机人体感应、生物标志物调试视窗入主界面（改为隐藏 URL 参数）、歌曲播放与歌单、实时口型数字人、医生端、家属端界面（仅定义接口契约）、真实硬件相框。

### **1.6 成功标准**

1. 家属端注入“海珠桥修自行车”记忆后 1 分钟内，患者端数字人能在对话中自然引用该记忆。  
2. 时空错位话术（“我要去上班”）获得顺应式安抚而非纠错。  
3. **双端真实上传 Demo 闭环**（见 F-P05）：全程无预置旁路数据，评委现场看着家属端上传 \-\> 患者端“长出”内容。

## **2\. 冷启动价值与个性化分层**

### **2.1 记忆分层金字塔**

L3 交互偏好层    \-- 眼动热力/高共鸣话题/对话风格，越用越懂老人（自动积累）  
L2 个人记忆层    \-- 家属语音留言/照片/口述史/声音样本注入（冷启动后持续生长）  
L1 公共时代记忆层 \-- 冷启动资产包（绑定时按 地区 \* 年代 \* 语言 即刻就位）

### **2.2 冷启动的价值论证**

* **冷启动是“第 0 天的地板”，不是天花板**：没有它，相框通电时是空壳——说不出老人听得懂的话题、展示不出熟悉年代的照片，家属第一印象就是“没用”，产品死于首次体验。冷启动保证**开箱即有 60 分**。  
* **个性化是持续上升的电梯**：家属每注入一条记忆，L2 权重上升；冷启动的 L1 内容**永不删除**，退居为“共同语言背景”——数字人聊海珠桥（L2 个人记忆）时，用的正是 80 年代广州（L1 公共背景）作为语境。L1 让 L2 说得“像那个年代的人”。

## **3\. 对话角色体系（双层角色）**

**核心原则：AI 永不以“AI/助手/机器人”身份出现在患者面前。** 后台 LLM 引擎始终隐身，仅通过“角色外壳”与老人对话（验证疗法的情感真实性要求）。对家属端的伦理披露策略见第 11 章。

### **3.1 第 1 层：常驻角色「老街坊」**

* 固定插画形象（呼吸微动动效）+ 固定名字（默认“强叔”，家属端可改名）。  
* 口吻设定为老人同龄街坊/故友，负责日常搭话、怀旧话题、日落安抚。  
* 无照片触发时，一切对话在该角色下进行。

### **3.2 第 2 层：照片亲人模式（Photo Persona）**

* **触发条件**（满足其一）：  
  * 老人**连续注视某张已标注照片达到 5 秒**（眼动追踪判定，复用注视热力能力）；  
  * 老人**开口说出照片人物的名字/称呼**（如“阿珍”“这是我老婆”，ASR \+ 记忆库人名匹配）。  
* **变身流程**：常驻角色说过渡语（“你看看这张照片……”）-\> 屏幕切换为该照片全屏 \-\> LLM 切换 Prompt 为该人物身份（“我就是阿珍呀”）-\> 以老伴/故人口吻对话。  
* **退出条件**：老人说“换个人聊聊”或静默 90 秒 \-\> 回常驻角色与待机轮播。  
* **前提**：家属端上传照片时**可选填**人物标注（名字 \+ 关系）。未标注照片不支持变身，仅参与普通轮播（保持家属端“随手传”低门槛）。

### **3.3 亲人声音匹配（声音克隆）**

* **数据来源**：家属端上传语音样本时可标注归属人（“这是阿珍的声音”），语音样本与照片人物通过**同一标注名**关联，形成 persona.voice\_sample。  
* **匹配逻辑**：照片亲人模式触发时，查该 persona 的 voice\_sample：  
  * **命中** \-\> 后端用零样本克隆（OpenVoice v2 / CosyVoice）以该音色合成 TTS——“阿珍用自己的声音”说话；  
  * **未命中** \-\> 回退默认 TTS 音色（当前语言对应音色），角色身份仍由 Prompt 承载。  
* **约束**：零样本克隆走后端预合成（上传样本时后台生成克隆音色配置并缓存），患者端只播音频，不承担克隆算力；克隆失败静默回退默认音色，绝不阻断对话。  
* **知情同意（硬性）**：家属端上传他人声音时必须勾选“我已获得本人或其监护人的同意”（见第 8、11 章）。

### **3.4 数字人形象三档渐进**

| 档位 | 形态 | 状态 | 说明 |
| :---- | :---- | :---- | :---- |
| **L1（P0 基线）** | 插画形象 \+ 呼吸微动 \+ 说话声波动画 | 必须交付 | 稳定、零依赖，保证 Demo 不翻车 |
| **L2（增强档）** | 照片亲人模式时，照片经 LivePortrait **预生成**“待机微动视频”（眨眼、轻微点头） | 时间富余则交付 | 上传照片时后台预生成视频缓存，规避实时生成延迟；效果已非常惊艳 |
| **L3（愿景）** | 音频驱动实时口型数字人（SadTalker / EchoMimic 类） | 不承诺，仅路演叙事 | 写入第 13 章落地展望 |

## **4\. 全局状态机**

患者端为单屏多状态应用，4 个状态。隐私确认与设备权限就绪后，待机默认持续监听。

| 当前状态 | 事件 | 下一状态 / 动作 |
| :---- | :---- | :---- |
| COLD_START | 云端配置与家属隐私确认就绪 | STANDBY，开始轮播和已授权采集 |
| STANDBY | 老人开口说话，或连续注视相框显示区域达到 5 秒 | CHAT；命中已标注人物时用亲人角色，否则用常驻角色 |
| CHAT | 老人静默达到 90 秒 | STANDBY；计时排除 AI 播报和模型等待时间 |
| STANDBY / CHAT | 当地时间 17:00（含）至 19:30（不含），且满足负面信号条件 | SOOTHING |
| SOOTHING | 连续 20 分钟无负面信号，或当地时间到达 19:30 | 停止背景音，返回 STANDBY，并提示家属端 |

**统一开口门槛**：只有老人开口说话或连续注视相框达到 5 秒，才开启一轮 AI 发言。一次触发允许完成对应回复及必要的角色过渡语，不自动连续追问；触屏、启动、定时器和状态切换本身不触发说话。此规则适用于 CHAT 和 SOOTHING。AI 播报及模型等待期间不累计新的注视触发；注视触发一次后，须移开视线至少 2 秒，再连续注视 5 秒才可重新触发。视线离开显示区域或追踪丢失时，连续注视计时清零。

**优先级**：满足舒缓条件时优先进入 SOOTHING，否则按人物匹配结果进入 CHAT。SOOTHING 内不因注视或人名匹配切回 CHAT，仅允许满足开口门槛的简短安抚回复，不主动提问。

**负面信号**：滚动 5 分钟内同一意图连续提问至少 3 次，或输入音量高于 -20 dBFS 持续 10 秒；计算与时区见 F-P04。

| 状态 | 界面 | 采集与监听 |
| :---- | :---- | :---- |
| COLD_START | 二维码、设备码与静态引导 | 不采集、不监听、不循环播报 |
| STANDBY | 照片轮播与监听开关 | 眼动、麦克风持续监听、ASR、音量检测；按授权上传保存 |
| CHAT | 数字人与大字幕 | 眼动、声学特征、ASR；按授权上传保存 |
| SOOTHING | 暖色、40Hz 白噪音背景、倾听形象 | 眼动用于开口门槛，持续监听和负面信号检测；按授权上传保存 |

## **5\. 功能模块详细需求**

### **F-P01 云端配置冷启动与设备绑定（COLD\_START）**

**交互流程**（患者端零操作）：

1. 首次启动展示大字“请家人扫码设置”+ 屏幕二维码（含 6 位设备码），不自动播放语音。  
2. 家属端扫码绑定 \-\> 家属端填写配置并确认隐私条款明细（见第 9、11 章）-\> 上传云端。  
3. 后端按配置（地区 \* 年代 \* 语言）**动态生成资产包**（详见下）-\> 患者端拉取配置 \+ 资产包 \-\> 直接进入 STANDBY。

**动态资产包生成（绑定时刻，一次生成终身缓存）**：

* 后端 LLM 收到组合（如“浙江-1970年代-普通话”），按固定 Prompt 模板联网搜索该组合的时代公共记忆（当地地标、标志性事件、生活场景），输出结构化资产包 JSON（照片关键词、对话话题库、Prompt 记忆锚点）；照片从搜索结果或公版资源获取；舒缓使用固定 40Hz 振幅调制白噪音素材，不生成歌单。  
* 生成约 10-30 秒，家属端显示“正在为老人准备专属回忆…”。  
* **三层兜底**：  
  1. 搜索成功 \-\> 动态资产包缓存至云端；  
  2. 失败/超时（30s）-\> 回退按年代划分的预置通用包（3 个，不分地区），标记“待补生成”，网络恢复后重试；  
  3. 黑客松现场保险：提前为 Demo 组合（广东-80s）预生成一份本地缓存，现场演示不赌网络。

**验收标准**：

* Given 首次启动，When 页面加载完成，Then 3 秒内出现二维码页面，无任何登录框/输入框；  
* Given 家属端完成配置并生成资产包，When 患者端轮询到就绪状态，Then 自动进入 STANDBY，轮播照片全部匹配“地区 \* 年代”；  
* Given 刷新页面，When 已绑定设备，Then 跳过绑定页直接进入 STANDBY（配置与资产缓存于本地 localStorage \+ 云端）。

### **F-P02 待机老照片轮播与监听（STANDBY）**

* 全屏照片每 10 秒切换，交叉淡入淡出至少 800ms。
* 隐私确认及麦克风授权后默认持续监听并进行 ASR。底部仅一个大尺寸麦克风监听开关，显示“监听中 / 监听已关闭”；点击只切换监听，不触发 AI 开口或进入 CHAT。
* 老人开口说话后进入 CHAT，识别完当前语句后回应；命中已标注人物名字/称呼时进入亲人模式，否则使用常驻角色。
* 连续注视相框显示区域达到 5 秒进入 CHAT。同一已标注照片连续注视达到 5 秒时优先使用该亲人角色，否则由常驻角色围绕当前照片开场。换图时重置照片级计时，相框级连续注视计时保留；重新触发规则见第 4 章。
* 关闭麦克风后停止新增音频采集、上传、ASR 与声音触发，注视触发仍可用；关闭摄像头后停止新增视频采集、上传与注视触发，语音触发仍可用。两者均关闭时仅轮播，不自动开口。
* 不定时搭话，不因触屏或进入待机而播报。

**验收标准**：

* Given 已授权的默认待机，When 老人说话，Then 无需触屏即可进入 CHAT 并在识别后回应。
* Given 老人不说话，When 连续注视不足 5 秒，Then AI 不开口；达到 5 秒时进入 CHAT 并开场。
* Given 同一已标注照片连续注视达到 5 秒，When 触发，Then 使用该亲人角色；未标注照片则使用常驻角色。
* Given 某照片连续注视达到 5 秒，When 上报，Then 该照片 ID 记入当日高共鸣列表。
* Given 已因注视发言，When 老人未移开视线重新触发，Then 不重复自动开口。
* Given 无说话或有效注视，When 轮播、触屏或恢复监听，Then AI 保持安静。
* Given 关闭监听，When 老人说话，Then 不采集、上传音频或触发回复。

### **F-P03 验证疗法双语对话（CHAT，含照片亲人模式与声音克隆）**

**交互循环**：语音触发时，先收音并完成当前语句的 ASR，再由 LLM 回复；注视触发时，基于当前照片及角色生成开场语。回复使用 TTS 0.85x 播报，同步大字幕及声波动画（L2 档为微动视频）。普通话回复 <= 40 字，英语回复 <= 40 词。播报结束后继续监听，下一轮发言仍须满足第 4 章开口门槛。

**核心规则**（验证疗法 Prompt 规范）：

* 时空错位输入（“我要去厂里上班”）-\> **严禁纠错**（禁止“退休/现在不是/你记错了”），顺应语境安抚（“今天厂里排休呢”）。  
* 家属端注入的记忆自然穿插引用。  
* 语言模式：仅普通话（`zh-CN`）与英语（`en`）；界面、ASR、TTS、字幕和 LLM 文案保持一致。MVP 不支持粤语，不随地区自动切换方言。

**照片亲人模式**（见第 3.2 节）：人名/称呼匹配触发或注视触发 \-\> Prompt 切换为该人物身份；**该 persona 存在语音样本时，TTS 使用其克隆音色**（见 3.3）。

**声学采集**：每轮对话记录犹豫潜伏期（AI 提问结束 \-\> 老人首次发声的 ms）、语速 WPM、停顿比率，随 session 上报。

**验收标准**：

* Given 老人说“我要去厂里上班了”，When LLM 返回，Then 回复不含纠错词且给出顺应式理由；  
* Given 家属端注入“海珠桥修自行车”记忆 1 分钟内，When 老人开启对话，Then 数字人 3 轮内主动提及该记忆；  
* Given 选择普通话模式，When 数字人播报，Then TTS 为普通话音色且字幕为普通话口语；  
* Given 老人注视已标注“阿珍/老伴”照片达到 5s，When 进入 CHAT，Then 数字人以阿珍身份应答；  
* Given 该“阿珍”persona 存在已克隆音色，When 阿珍角色播报，Then TTS 使用克隆音色；Given 音色克隆失败，Then 静默回退默认音色且对话不中断；  
* Given 老人静默 90 秒，When 无语音输入，Then 自动返回 STANDBY。

### **F-P04 日落综合征舒缓模式（SOOTHING）**

**触发条件**（全部满足）：用户当地时间 17:00（含）至 19:30（不含）；处于 CHAT/STANDBY；监听开启；满足以下任一负面信号条件。

| 参数 | MVP 固定规则 |
| :---- | :---- |
| 重复提问 | 滚动 5 分钟内同一意图连续出现至少 3 次老人提问。按 ASR 最终语句归类，每句计一次；不同意图的老人提问重置连续计数，AI 发言不计数，过期记录移除 |
| 声音阈值 | 归一化 PCM 每 100ms 计算 RMS，`dBFS = 20 × log10(max(RMS, 1e-8))`；连续 100 个窗口高于 -20 dBFS，即持续 10 秒，触发；任一窗口不达标则清零连续计时 |
| 阈值含义 | -20 dBFS 为数字输入幅度，不是环境声压分贝。MVP 不做个体校准或动态阈值 |
| 自身播放 | MVP 不处理自身 TTS 或背景音的回声消除、扣除或来源识别；自身播放被采集时也可能参与判定 |
| 时区 | 优先使用患者设备浏览器获取的 IANA 用户时区，同步云端；获取失败或无效时用 `Asia/Shanghai`（东八区 UTC+08:00）。时段按该时区计算，持续时长按经过时间计算 |

**执行动作**：

1. 中断当前问答，屏幕以 3 秒渐变切暖黄。
2. 满足第 4 章开口门槛时，说一次过渡语“天快黑了，我陪你安静待一会儿”；仅由音量触发且未满足开口门槛时静默切换。
3. 循环播放固定 **40Hz 白噪音背景**。本 PRD 将其定义为 **40Hz 振幅调制的白噪音素材**，不是 40Hz 单频纯音；作为背景音设计，不据此承诺治疗效果，不新增独立 GAMMA 模式。
4. 不播放歌曲、不生成歌单、不显示歌名。数字人保持倾听姿态，仅在老人说话或重新达到注视门槛时简短安抚，不主动提问、不定时说陪伴语。

**退出与家属提示**：

* 连续 20 分钟无上述负面信号，或用户当地时间到达 19:30，立即停止背景音并返回 STANDBY。19:30 到点即退出，即使仍有负面信号也不延长。
* 每次退出提交一次 `soothing_exited` 事件，后端向已关联的授权家属展示提示。退出不等待通知完成；正常联网时退出后 5 秒内提交，家属在线时于服务端收到事件后 5 秒内展示；离线家属下次打开时可见。
* 事件包含唯一 `event_id`、患者 ID、退出时间、用户时区、舒缓持续时长、退出原因（`time_window_end` / `settled_20min`）与退出时是否仍有负面信号。
* 到点提示：“相框已于当地时间 19:30 结束舒缓模式”；仍有信号时追加“结束时仍检测到重复提问或持续高音量，请留意老人状态”。
* 患者端断网时暂存事件，恢复后补报，后端按 `event_id` 去重。退出不自动播报；仍在允许时段内时清空触发计数，须新的完整条件才再次进入。

**验收标准**：

* Given 当地时间 17:30，When 5 分钟内同一意图连续第 3 次提问识别完成，Then 30 秒内进入舒缓；超出窗口的提问不凑次数。
* Given 允许时段内，When 输入连续 10 秒高于 -20 dBFS，Then 触发舒缓；中间不达标则重新计时。
* Given 用户时区为 `America/New_York`，When 当地时间到达 17:00 / 19:30，Then 按当地时段启用 / 退出；获取失败时使用东八区。
* Given 进入舒缓，When 页面与音频就绪，Then 暖黄界面配 40Hz 振幅调制白噪音，无歌曲、歌名、主动提问。
* Given 19:30 到点且仍有信号，When 检查，Then 停止背景音、回待机，并按约定时限提示家属当前信号状态。
* Given 连续 20 分钟无负面信号，When 检查，Then 退出并提示家属，原因为 `settled_20min`。
* Given 退出时断网，When 恢复连接，Then 补报事件，家属仅收到一次提示。

### **F-P05 双端真实上传 Demo 闭环**

**定位**：面向评委与开发自测的**全流程真演示**——全程无预置旁路数据，所有患者端内容由家属端真实上传产生。

**Demo 脚本**（约 3 分钟）：

**验收标准**：

* Given 全新设备 \+ 全新家属账号，When 按 Demo 脚本执行，Then 每步在 1 分钟内于患者端可见生效（照片出现/记忆被引用/克隆音色播报）；  
* Given ?demo=1 且拒绝摄像头/麦克风权限，When 走完整流程，Then 所有状态转移正常、无白屏/卡死；  
* Given Demo 模式对话，When 输入假语音文本“我要去厂里上班”，Then 返回顺应式安抚回复。

## **6\. 埋点指标**

> 定位声明：以下指标为**认知活力与情绪状态的日常参考**，供家属端简报与照护沟通使用，**不构成任何医学诊断或筛查结论**。

| 指标 | 采集时机 | 用途 |
| :---- | :---- | :---- |
| session 时长、各状态停留时长 | 全局 | 认知活力参考因子（供家属端简报） |
| 犹豫潜伏期 / 语速 WPM / 停顿比率 | 每轮对话 | 声学参考指标 |
| 注视热力（照片级注视时长） | STANDBY / CHAT | 高共鸣话题（供家属端话题推荐） |
| 时空错位事件计数 \+ 类型标签 | CHAT | 家属端重点提示 |
| 照片亲人模式触发次数、涉及人物、是否使用克隆音色 | CHAT | 亲情联结度（供简报） |
| 日落触发次数 / 舒缓停留时长 / 退出原因 / 退出时负面信号 | SOOTHING | 舒缓记录与家属退出提示 |

上报数据结构沿用 Biomarker Payload 规范，扩展字段：mode（chat/soothing）、persona（resident/photo:{memory\_id}）、voice（default/cloned）。

## **7\. 账户与鉴权**

### **7.1 患者：无账号，只认设备**

* 患者端**无任何登录概念**。首次启动生成/展示 6 位设备码（随二维码呈现），家属端扫码完成绑定。  
* 绑定成功后服务端下发**设备 token**（一次性下发，持久有效直至解绑），患者端后续所有接口凭该 token 访问。  
* 患者 ID 为服务端随机串（如 p\_88329），不含姓名/手机号等明文个人信息。

### **7.2 家属：微信手机号登录，多家属多患者**

* **登录方式**：微信手机号一键登录（MVP 简化版可为手机号 \+ 验证码）。  
* **绑定关系**：family\_user \--(care\_relation)--\> patient，**一个患者可绑定多名家属**，**一个家属可关联多位患者**（覆盖独子照顾双亲的常见场景）。  
* **家属角色**：  
  * **管理员**（首个绑定的家属）：可修改患者配置（年代/地区/语言/角色名）、管理其他家属成员、解绑设备；  
  * **成员**：可上传记忆留言、照片（含人物标注）、语音样本（含同意勾选），查看每日简报。  
* **操作审计**：所有家属写操作（记忆注入/照片/语音样本）带操作者 ID 与时间戳入库。

### **7.3 端与界面的区分**

* 患者端（相框全屏 Web）：仅凭设备 token 拉取数据，无任何家属可见功能；  
* 家属端（手机 H5/小程序）：凭用户登录态，首屏为“我关联的老人”列表，进入某患者后才能上传/查看该患者数据——**界面与权限天然按“家属 \-\> 患者”路径隔离**。  
* 越权防护：设备 token 仅能读取所属患者的资产与上报数据；家属 token 仅能操作其 care\_relation 关联的患者。

## **8\. 非功能需求**

### **8.1 适老化**

* 核心文本字号 \>= 32pt，色彩对比度 WCAG AAA（\>= 7:1）。  
* TTS 语速 0.85x，音调增强中低频共鸣。  
* 全流程老人操作 \<= 2 次点击，零文字输入。

### **8.2 隐私与加密**

* 患者原始音频、原始视频、ASR 转写、完整对话文本、采集特征，以及家属照片、声音样本及克隆产物，均加密保存至云端患者空间。眼动与声学特征可本地计算，但不再承诺原始音视频永不上传。
* 全链路 HTTPS/TLS；数据库、对象存储与备份启用静态加密，密钥与业务数据分离管理。访问受第 7 章鉴权约束，媒体使用鉴权后的短期签名地址。
* 首次采集前家属确认隐私条款明细并留存记录（见 11.4）；设备仍需浏览器麦克风与摄像头权限。确认前不采集、不上传；确认并授权后待机默认监听，按第 4 章状态表采集上传。
* 页面显示麦克风及摄像头工作状态并提供关闭入口；关闭立即停止对应新增采集和上传，不自动删除云端历史数据。
* 云端 ASR 处理授权音频，后端 LLM 使用授权转写与必要记忆；服务商、用途、存储地点和期限须在隐私明细中展示。
* 授权家属可按患者查看完整对话和授权数据。家属删除时级联清理关联原始文件、文本、特征、向量记忆、克隆音色与微动视频缓存；保留期限、备份清除周期及删除完成时限以已展示并确认的服务端隐私策略为准。

### **8.3 降级策略**

* LLM 不可达 \-\> 回退本地预置话术库（\>= 20 条，按语言分组），保证 Demo 不冷场。  
* 资产包生成失败 \-\> 三层兜底（见 F-P01）。  
* 声音克隆失败 \-\> 静默回退默认音色（见 3.3）。  
* ASR 失败/超时 \-\> 数字人温和重复上一句，不报错、不显示任何错误提示给老人。

### **9.1 家属端须提供的配置项（绑定流程）**

| 配置项 | 取值 | 患者端用途 |
| :---- | :---- | :---- |
| 出生年代 | 50年代 / 60年代 / 70-80年代 | 资产包年代维度 |

### **9.2 家属端须提供的数据通道**

1. **设备绑定**：扫码（含 6 位设备码）-\> 写入配置与隐私确认记录 \-\> 触发资产包生成 \-\> 患者端轮询就绪。  
2. **增量记忆注入**（POST /api/family/memory/add）：语音/文本 \-\> NER 抽取 \-\> 记忆节点。患者端对话引擎读取记忆库，1 分钟内生效。  
3. **照片上传 \+ 人物标注（可选）**：照片 \+ {名字, 关系} 标注 \-\> 照片亲人模式的变身依据；L2 档同时触发 LivePortrait 微动视频预生成。未标注照片仅参与轮播。  
4. **语音样本上传 \+ 归属标注 \+ 同意勾选（可选）**：语音（数秒即可）+ 归属人名 \+ 勾选“我已获得本人或其监护人的同意” \-\> 后台零样本克隆生成该 persona 音色配置 \-\> 照片亲人模式命中。归属人名与照片人物标注名**精确匹配**即关联。

### **9.3 患者端回流给家属端的数据**

每日简报所需原料：认知活力参考评分因子（第 6 章埋点）、高共鸣话题（注视热力 Top N）、时空错位事件、照片亲人触发记录（含克隆音色使用情况）、日落舒缓触发与退出记录；退出时的即时家属提示须包含 F-P04 指定字段，并按其时限、补报及去重规则处理。

## **10\. 临床依据（专业融合）**

## **11\. 免责与伦理设计**

### **11.1 免责声明（患者端首次绑定后于家属端展示，并存档）**

* 本系统是**陪伴与照护支持工具，不是医疗器械**；不进行诊断、筛查判定或治疗建议；所有指标仅供日常参考，异常情况请咨询专业医师。

### **11.2 AI 身份披露策略（伦理张力的正面处理）**

* **对患者**：AI 在对话中以“老街坊/亲人”身份出现，不主动自我披露——这是验证疗法的临床要求（“机器人陪聊”标签会立即摧毁信任）。此设计决策在 PRD 与路演中**公开说明**，不隐瞒。  
* **对家属**：家属端在绑定流程中明确告知“数字人由 AI 驱动、对话内容经 LLM 生成”，并提供完整对话记录可查——知情权完整保留在监护侧。  
* **边界**：数字人被老人直接追问“你是不是机器人”时，不得撒谎（“我是陪你聊天的伙伴”，转移话题），不得断言自己是人类。

### **11.3 声音与影像克隆知情同意**

* 家属端上传他人语音样本/照片用于克隆时，必须勾选“我已获得本人或其监护人的同意”方可提交，同意记录入库；  
* 克隆音色仅用于该患者本人交互，不跨患者复用；  
* 家属删除照片/语音样本时，级联删除克隆音色与微动视频缓存；  
* 对患者播放克隆语音时，该 persona 对话界面角落常驻小字样提示（家属端演示与录屏中可见，字号对老人不构成干扰）。

### **11.4 云端保存与隐私条款确认**

* 首次绑定时家属端展示隐私条款明细，家属主动勾选后提交；不默认勾选、不以无操作自动确认代替。声音与影像克隆仍须另行满足 11.3 的同意要求。
* 明细逐项说明：待机持续监听及各状态的采集范围；原始音视频、转写、完整对话、特征、照片和声音样本的云端加密保存；ASR、LLM、TTS、克隆及家属查看的用途和数据接收方；存储地区、各类数据保留期限、备份清除周期与删除时限；家属访问范围；关闭采集、撤回同意和删除的入口及功能影响。
* 上述明细由服务端隐私策略提供具体值，缺项时不得启用采集。记录确认人 ID、患者 ID、条款版本、明细快照及时间，允许家属后续查阅。新增授权范围须重新确认。
* 撤回同意后，服务端通知设备停止新增采集、上传及相应云端处理；历史数据按确认条款及删除请求处理，再次启用需要重新确认。
* 患者 ID 去标识化；完整对话加密保存在云端供授权家属查看。存储与删除遵循 8.2，不再承诺整个业务链路零数据保留。

## **13\. 落地展望（孵化与公益路径）**

* **社区养老机构**：相框设备 \+ 家属端订阅，机构护理员以“管理员家属”角色批量管理，缓解护理员沟通压力——B2B2C 路径；  
* **残联/公益基金会合作**：面向认知症家庭的公益捐赠版本，家属端免费、按需付费硬件；  
* **硬件化路线**：浏览器架构天然可移植至安卓相框/树莓派一体机（Web 容器 \+ 物理防窥滑盖 \+ 麦克风断电开关）；  
* **L3 数字人愿景**：音频驱动实时口型（SadTalker/EchoMimic 类）+ 更长录音微调克隆，让“亲人复活对话”完全体落地；  
* **记忆资产的家庭传承价值**：老人与数字人的对话记录、口述内容经家属授权沉淀为“家庭记忆库”，反哺每日老故事连环画——产品情感价值随时间复利增长。

## **15\. 前端拟物化相框与路演架构（增补规范）**

### **15.1 拟物化外壳（Skeuomorphic Frame）层叠模型**

1. **胡桃木外框（Wood Grain Border）**：  
   * 采用 CSS 多层渐变（Linear Gradients）与阴影堆叠，呈现胡桃木深褐色质感，带有 1px 亮色倒角高光线与四周漫反射投影（box-shadow: 0 25px 50px \-12px rgba(0,0,0,0.5)）。  
2. **斜切衬垫（Mat Board / Passe-Partout）**：  
   * 传统照片装裱米白色卡纸质感，内边缘带向内下沉阴影（box-shadow: inset 0 3px 6px rgba(0,0,0,0.35)），强化相片陈列装裱感。  
3. **物理五金微刻点缀**：  
   * **顶部中央**：拟物绘制前置微型摄像头孔点与麦克风收音网孔；右侧配有极微弱的绿色呼吸微光（指示已授权摄像头采集正常运转；数据按隐私条款加密保存云端）。  
   * **右下角/背板**：金属烫金细字微标 Vital Memory · 忆伴。

### **15.2 “双重视口”架构：老人沉浸模式 vs 评委全知 HUD 模式**

为了兼顾“老人界面的极致极简”与“评委对眼动、声学、验证疗法后台机制的直观理解”，前端实行双重视口动态解耦：

                    \+-------------------------+  
                    | 快捷键 'D' 或参数 ?hud=1 |  
                    \+------------+------------+  
                                 |  
           \+---------------------+---------------------+  
           v                                           v  
           +-----------------------+                   +-------------------------------+  
    |   老人纯净相框模式     |                   |      评委演示全知模式         |  
    |   (Pure Frame Mode)   |                   |      (Judge HUD Mode)         |  
    +-----------------------+                   +-------------------------------+  
    | * 无任何技术参数      |                   | * 主相框等比左移缩放          |  
    | * 仅老照片、大字幕    |                   | * 右侧滑出半透明磨砂 HUD 面板 |  
    | * 极简大触控麦克风    |                   |   - 虹膜视线注视点实时十字光斑|  
    | * 适老化高对比度      |                   |   - 语速(WPM)/停顿潜伏期曲线  |  
    |                       |                   |   - 验证疗法 Prompt 命中意图  |  
    |                       |                   |   - 当前 TTS 音色来源标注     |  
    +-----------------------+                   +-------------------------------+


* **老人纯净模式（默认）**：全屏展示，无任何技术标签、FPS 计数器或调试视窗，严格符合适老化无负担原则。  
* **评委全知 HUD 模式（快捷展开）**：  
  * 点击相框左上角隐蔽区域或按键盘 D 键（或 URL 参数 ?hud=1），主相框区域平滑向左平移，右侧滑出磨砂黑 HUD 遥测抽屉。  
  * **HUD 实时呈现内容**：  
    1. 虹膜追踪注视点（Gaze Point）十字准星与注视时长累计进度槽（直观向评委解释为何触发照片变身）；  
    2. 声学特征流（Web Audio 采集的 WPM 语速、停顿潜伏期数值）；  
    3. 验证疗法 Prompt 意图解析（如：“识别到时空错位，执行顺应式安抚：不纠错”）；  
    4. 当前声音音色标识（Resident: 强叔 / Persona: 阿珍 (Cloned Voice)）。

### **15.3 四大状态前端动效视觉细则**

1. **COLD\_START（首次配置）**：  
   * 界面意象为“桌上一封未启封的书信”；  
   * 居中呈现墨水楷体温和提示，大号二维码带柔和扩散光晕动效；下方以 36pt 等宽清晰字体排列 6 位设备码；  
   * WebSocket 收到家属端绑定成功事件后，二维码呈墨滴晕开动画（淡出时长 \>= 1.2s），首张年代照片缓慢显影。  
2. **STANDBY（待机老照片轮播）**：  
   * **Ken Burns 电影感视效**：照片以极慢速度（10s 内从 scale(1.0) 缓动至 scale(1.05)，平移 \<= 2%），叠加微妙的老胶片微暗角（Vignette Filter）；  
   * 切换照片时淡入淡出时长 \>= 800ms；  
   * 底部常驻微光呼吸的麦克风浮动按钮（直径 \>= 72px）；照片左下角短暂浮现年代地点标签（3s 后自动隐去）。  
3. **CHAT（验证疗法陪聊 & 照片亲人变身）**：  
   * **常驻老街坊形象**：手绘和善水彩半身插画，CSS 实现轻微胸腔起伏呼吸动效（周期 3s）；发声时身旁扩散柔和同心涟漪声波环；  
   * **适老大字幕**：字号 \>= 34pt，胶囊高对比深色背景，配合逐字平滑高亮；  
   * **照片亲人变身高光转场**：连续注视达到 5s 判定生效后，常驻角色温和念出过渡语，老照片居中瞬间平滑放大至全屏，四周边缘泛起暖金景深光斑，克隆声音介入。  
4. **SOOTHING（日落综合征舒缓）**：  
   * 触发时全屏经 CSS Filter 3s 渐变到 2700K 暖黄烛光色温（sepia(0.35) saturate(1.2)）；  
   * 数字人转为静默抱膝/托腮倾听姿态；  
   * 屏幕中央保留高共鸣老照片与缓慢呼吸光晕，背景播放 40Hz 振幅调制白噪音；不显示黑胶唱片、歌名或技术频率标签。

### **15.4 前端防呆与鲁棒性交互设计**

1. **防误触与零认知负担（Zero-Cognition Load）**：  
   * 禁用右键菜单、双指捏合缩放（touch-action: manipulation; user-select: none;）；  
   * 彻底摒弃一切输入框、下拉选单与右上角微小关闭叉号（×）；  
   * 所有触控目标区域最小尺寸 \>= 64px。  
2. **隐藏式运维暗门**：  
   * 演示者快速连续点击相框右上角 3 次，可唤起轻量级运维菜单（提供：重置绑定设备码、手动触发日落模式、切换普通话 / 英语双语演示流）。  
3. **权限降级温和处理**：  
   * 若麦克风/摄像头被浏览器弹窗拦截，界面不显示红色“403 / 权限错误”，而是由强叔以漫画对话框形式温和提示：*“强叔耳朵有点背，请在浏览器上方允许使用麦克风哦”*。
